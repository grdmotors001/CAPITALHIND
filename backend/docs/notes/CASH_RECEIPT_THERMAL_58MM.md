# Cash Collection Receipt – 58mm Thermal Printer

Implemented in STEP 11.5.

- Primary format: 58mm pocket thermal printer
- Cash collection receipt only; non-cash admin receipts retain existing A4-style print
- Includes receipt no., date/time, customer, mobile, loan/application, vehicle, collector, cash mode, amount, remarks and signature lines
- Principal/interest/penalty breakup is shown only when those values are actually supplied; no fake breakup is generated
- Browser Print Receipt opens a print window and does not create another collection/payment entry
- Existing receipt number remains unchanged on re-print
